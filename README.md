# Omachines

A native Omarchy bar panel for Windows VM controls, agent connections and backups.

The first implementation is under review in a pull request. See the
[open pull requests](https://github.com/atlastimed/Omachines/pulls) for the code,
integration requirements, validation evidence and installation instructions.

This is an early preview tested with one existing Omarchy Windows setup.
Optional SSH, Cua, Aside and backup features need separately configured local
bridges; they are not bundled. Omachines does not install Windows or restore VM
backups. No VM images, credentials or private host configuration belong here.

MIT licensed. Not submitted to the Omarchy plugin marketplace.
